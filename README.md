# わんこそば式 TODO

目の前のタスクを裁くのが好きな人のための TODO アプリ。

普通の TODO アプリは全体像を先に見せる。残り件数、期限、優先度。計画を立てたい人には有用だが、
手を動かしたい人にとっては着手前の消耗でしかない。「あと 37 件」を見た瞬間に手が止まる。

このアプリは逆を行く。わんこそばの給仕のように、目の前には常に **1 杯（1 タスク）だけ**を出す。
食べ切った瞬間、考える隙を与えずに次が注がれる。残りが何杯あるかは、処理中には見せない。

## 3 つの画面

| 画面 | 役割 |
|---|---|
| **釜** | 仕込み場所。全体量が見える唯一の画面。改行区切りで一括投入できる |
| **食事処** | 本体。1 件だけを大きく出す。残数・一覧・進捗は一切出さない |
| **お会計** | 振り返り。杯数、所要時間、一杯あたりの時間、食べたものの一覧と履歴 |

## 使い方

```bash
pnpm install
pnpm dev
```

- **Enter / Space** で完了。連打でテンポを作るのがこのアプリの肝
- **ひとつ戻す** で直前の完了を 1 段だけ取り消せる（連打で誤爆しても大丈夫）
- 食事処の下部から**その場で追加投入**できる。投入したものはプールの末尾に入る
- 積み上がるお椀は「食べた数」であって「残り」ではない

タスクの消化順は登録順（FIFO）。スキップや選び直しはない。判断させないことが設計意図。

## データ

localStorage（キー `wanko-todo/v1`）にのみ保存する。サーバーには何も送らない。
保存データが壊れていた場合は初期状態にフォールバックする。

## 構成

```
src/
  App.tsx                 画面モードの切り替えとキーボード操作
  types.ts
  storage.ts              localStorage の読み書きと検証
  format.ts               時間・日付の表示整形
  state/appReducer.ts     純粋 reducer + 派生セレクタ
  screens/                PoolScreen / ServingScreen / SummaryScreen
  components/             BowlStack / QuickAdd
  styles.css
```

状態は `useReducer` に集約している。現在のタスクや杯数などの派生値は state に持たず、
`appReducer.ts` のセレクタで常に算出する（二重管理によるズレを避けるため）。
時刻は必ずアクションの `at` で渡し、reducer は純関数に保っている。

## スコープ外

外部サービス連携、繰り返しタスクの自動再投入、コンボ／ストリーク、効果音。
